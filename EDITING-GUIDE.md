# Editing the website

Follow README.md for the current Node.js 24.x install/build/test and GitHub/Vercel steps. The project has a required build step; Vercel serves `dist/`.

Keep product IDs, image paths and English translation keys consistent. The legacy internal ID `kabi-haran` is retained for existing links. Product information lives in product-data.js; ingredient content lives in ingredient-data.js. Only change verified brand facts. Preserve oral versus external-use distinctions, medical wording, doses and precautions.

Edit rupee prices only in store-config.mjs. The cart converts them internally to paise. The build and schema use the same price source; never multiply configuration prices by 100 or edit generated price copies.

The Formspree endpoint remains in site-settings.js. Cart checkout prepares a WhatsApp/email enquiry; it is not a paid or confirmed order. Translations load when the visitor selects a language. Review all seven dictionaries for new English interface text.

Shared styling remains in styles.css; cart-specific enquiry styles remain in cart-checkout.css. Source files that were already compacted remain compacted outside focused changes. Do not minify editable source by hand. Build-only optimization creates the deployed copies.

Category, contact and educational HTML is regenerated by scripts/seo-pages.cjs. Update that source/settings rather than editing generated page copies that the next build would overwrite. Keep vercel.json routing synchronized with scripts/build-search.cjs.

Keep IMAGE_CREDITS.md and the source/author/licence fields when editing ingredient photographs. Preserve full-size label photos for the enlarged-image viewer. Run the entire build/test sequence before uploading any changes.
